# Selin Yücel – Personal Portfolio

A personal portfolio website for a Frontend Developer. It includes an About section, skills, courses, and contact information.

- Responsive navigation menu
- About and skills sections
- Course cards
- Contact form

## Technologies

- HTML
- CSS
- JavaScript
- Bootstrap

## Getting Started

Download or clone the repository, then open `index.html` in your browser. You can also use a tool such as VS Code Live Server while developing.

## Note

This project provides a frontend portfolio interface. The contact form needs a backend or a form service to send messages.
